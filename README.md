# Wang-Haining.github.io-src

Source for my personal website, [hainingwang.org](https://hainingwang.org).
Built with [Pelican](https://getpelican.com/); the rendered site lives in the `output` submodule.

Build: `pelican content -o output -s publishconf.py`, then `python tools/check_seo.py output`.
If `content/pages/home.md` or `about.md` changes, regenerate `llms-full.txt` with `python tools/build_llms.py`.
Deploy: commit and push `output` (branch `master`) first, then commit the updated submodule pointer here on `main`.
Stage files by name here; the repo root holds local folders that should stay untracked.

Publications live in `data/publications.toml`; `content/pages/research.md` only sets the template.
News items go at the top of `### What's New` in `content/pages/home.md`, newest first.
Hourly sidebar palettes are generated by the scripts in `tools/palettes`.
The theme is Flex, checked out next to this repo at `../pelican-themes/Flex`; local overrides are in `templates/`.
Pages: `content/pages/` (home, research, resource, teaching, contact).
The stylometry lab for the Under Five series is a static app in `content/teaching/stylometry/`.
